# BeBold

A Chrome extension that bolds the start of each word to give your eye an anchor.

- [Privacy policy](PRIVACY.html)
- [Source code](https://github.com/cdukedev/BeBold)
- [Chrome Web Store](https://chromewebstore.google.com/detail/bebold/ckgjflmajkijpaipoijlpleihipnpjma)

BeBold makes no network requests of any kind. It collects nothing, sends nothing, and
stores only your settings in Chrome's own sync storage.
